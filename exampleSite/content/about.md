本页演示一篇关闭目录与评论的普通页面。

## 为什么有这个站点

这个站点是 Inkwell 主题自带的示例，同时也是验收样本：它覆盖了主题支持的各种内容形态，包括代码很多的技术文章、一篇长篇随笔、一篇图文笔记、一个三篇的系列，以及带公式和图表的文章。所有文字都是为演示而写的，可以随意删改。

## 主题适合谁

Inkwell 适合想认真写字、认真读字的人：个人博客、技术笔记、读书札记、文档站。它刻意保持克制，没有封面大图、没有社交分享按钮，也不做统计。页面里能看见的东西，大多是为了让读文章这件事更顺手。

## 如何使用示例站点

克隆仓库后，在仓库目录下运行 `hugo server --source exampleSite` 就可以预览。目录名需要是 `Inkwell`，因为示例站点用 `themesDir = "../.."` 引用上级目录里的主题。想把示例换成自己的站点，复制 README 里的“必须复制的站点配置”即可。
